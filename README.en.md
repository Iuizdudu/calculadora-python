<a id="about"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=ABOUT+THE+PROJECT" width="500"/>

An ultra-realistic simulation of the **Native Windows 10/11 Calculator**, built with modern Fluent Design aesthetics, full custom theme support, and deep **Python** code & terminal integration.

> [!NOTE]
> Unlike typical web calculators that distort numeric layouts, this application preserves the classic 3x3 telephone keypad (`7-8-9`, `4-5-6`, `1-2-3`, and `+/- 0 ,`) **in the exact same position across all modes**.

> [!TIP]
> Full physical keyboard support: use number keys `0-9`, comma/dot `.`, operators `+ - * / ^`, `Enter` or `=` to calculate, `Backspace` to delete, and `Esc` or `C` to clear.

<a id="modes"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=CALCULATOR+MODES" width="500"/>

| Mode | Icon | Features |
| :--- | :---: | :--- |
| **Standard** | 🧮 | Basic arithmetic with `%`, `CE`, `C`, `⌫`, `¹/x`, `x²`, `²√x`, `+/-` and full memory registers (`MC`, `MR`, `M+`, `M-`, `MS`, `M▾`). |
| **Scientific** | 🔬 | Trigonometry (`sin`, `cos`, `tan`), inverses (`2nd`), hyperbolic (`sinh`, `cosh`, `tanh`), `DEG`/`RAD`, `ln`, `log₁₀`, `log₂`, `xʸ`, `10ˣ`, `eˣ`, `n!`, `π` and `e`. |
| **Programmer** | 💻 | Simultaneous quad-view in **HEX**, **DEC**, **OCT**, and **BIN** (grouped in 4-bit nibbles), **QWORD**, **DWORD**, **WORD**, **BYTE** selection, and bitwise logic (`<<`, `>>`, `NOT`, `CLR`). |
| **Date Calculation** | 📅 | 1) **Difference between two dates** in years, months, weeks, and total days.<br>2) **Add or subtract periods** with instant output date calculation. |
| **Converters** | 🔄 | Suite with **10 unit categories**: Currency (Real exchange rates), Volume, Length, Weight/Mass, Temperature, Energy, Area, Speed, Time, and Power. |

> [!IMPORTANT]
> In **Programmer Mode**, the keypad automatically adapts to the selected numeral base: in binary (BIN) only keys `0` and `1` are active; in hexadecimal (HEX), keys `A` through `F` are enabled.

```bash
# 1. Clone repository
git clone https://github.com/your-username/python-scientific-calculator.git
cd python-scientific-calculator

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

Open `http://localhost:3000` in your browser.
