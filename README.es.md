<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=ACERCA+DEL+PROYECTO" width="500"/>

Una simulación fiel y de alta precisión de la **Calculadora Nativa de Windows 10/11**, desarrollada con estética moderna Fluent Design, soporte para 11 temas personalizados e integración con **Python**.

> [!NOTE]
> A diferencia de calculadoras web tradicionales, el teclado numérico telefónico (`7-8-9`, `4-5-6`, `1-2-3` y `+/- 0 ,`) **permanece exactamente en la misma posición** en todos los modos.

> [!TIP]
> Soporte completo para teclado físico: use números `0-9`, coma o punto `.`, operadores `+ - * / ^`, `Enter` o `=` para calcular, `Backspace` para borrar y `Esc` o `C` para reiniciar.
