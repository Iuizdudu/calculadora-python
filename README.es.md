<a id="acerca"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=ACERCA+DEL+PROYECTO" width="500"/>

Una simulación fiel y de alta precisión de la **Calculadora Nativa de Windows 10/11**, desarrollada con estética moderna Fluent Design, soporte para 11 temas personalizados e integración con **Python**.

> [!NOTE]
> **Nota:** A diferencia de calculadoras web tradicionales, el teclado numérico telefónico (`7-8-9`, `4-5-6`, `1-2-3` y `+/- 0 ,`) **permanece exactamente en la misma posición** en todos los modos.

> [!TIP]
> **Consejo:** Soporte completo para teclado físico: use números `0-9`, coma o punto `.`, operadores `+ - * / ^`, `Enter` o `=` para calcular, `Backspace` para borrar y `Esc` o `C` para reiniciar.

<a id="modos"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=MODOS+DE+OPERACION" width="500"/>

| Modo | Ícono | Características Principales |
| :--- | :---: | :--- |
| **Estándar** | 🧮 | Aritmética básica con `%`, `CE`, `C`, `⌫`, `¹/x`, `x²`, `²√x`, `+/-` y barra de memoria completa (`MC`, `MR`, `M+`, `M-`, `MS`, `M▾`). |
| **Científica** | 🔬 | Trigonometría (`sin`, `cos`, `tan`), inversas (`2nd`), hiperbólicas (`sinh`, `cosh`, `tanh`), `DEG`/`RAD`, `ln`, `log₁₀`, `log₂`, `xʸ`, `10ˣ`, `eˣ`, `n!`, `π` y `e`. |
| **Programador** | 💻 | Visor cuádruple simultáneo en **HEX**, **DEC**, **OCT** y **BIN** (agrupados en nibbles de 4 bits), selección **QWORD**, **DWORD**, **WORD**, **BYTE** y operadores bit a bit (`<<`, `>>`, `NOT`, `CLR`). |
| **Cálculo de Fecha** | 📅 | 1) **Diferencia entre dos fechas** en años, meses, semanas y total de días.<br>2) **Sumar o restar períodos** con cálculo instantáneo de la fecha resultante. |
| **Convertidores** | 🔄 | Central con **10 categorías de unidades**: Moneda, Volumen, Longitud, Peso/Masa, Temperatura, Energía, Área, Velocidad, Tiempo y Potencia. |

> [!IMPORTANT]
> **Importante:** En el **Modo Programador**, el teclado numérico se adapta a la base seleccionada: en binario (BIN) sólo `0` y `1` están activos; en hexadecimal (HEX), se habilitan las teclas de la `A` a la `F`.

> [!WARNING]
> **Advertencia:** Al cambiar el tamaño de palabra de **QWORD** (64 bits) a **BYTE** (8 bits), los valores que excedan el límite serán truncados por la máscara de bits.

<a id="instalacion"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=INSTALACION" width="500"/>

```bash
# 1. Clonar el repositorio
git clone https://github.com/su-usuario/calculadora-cientifica-python.git
cd calculadora-cientifica-python

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor local
npm run dev
```

> [!IMPORTANT]
> **Importante:** El archivo `.npmrc` incluye `legacy-peer-deps=true` para garantizar una instalación limpia sin conflictos de dependencias.

> [!TIP]
> **Consejo:** Para compilar los archivos de producción, ejecute `npm run build`.

<a id="python"></a>
<img src="https://readme-typing-svg.herokuapp.com?font=Lexend+Giga&size=24&pause=1000&color=0078D4&vCenter=true&width=500&height=28&lines=MOTOR+PYTHON" width="500"/>

1. **Traducción en Tiempo Real**: Cada cálculo genera su fórmula en Python (`import math; ...`).
2. **Terminal Python Interactivo**: Consola para probar fórmulas matemáticas directamente en el navegador.
3. **Script Autónomo (`calculadora_cientifica.py`)**:
   - Python puro sin paquetes externos (`tkinter` y `math`).
   - Ejecución por GUI o por consola:

```bash
# Ejecutar con interfaz gráfica Tkinter
python calculadora_cientifica.py

# Ejecutar en modo terminal CLI
python calculadora_cientifica.py --cli
```
